## 概念稿 02 与实机 HUD 的已知差异

| 项 | 概念稿 02 | 实机（当前口径） |
| --- | --- | --- |
| 生命/体力 | 左上长条血条 + 体力条 | 左上双圆球（铁框 + 液面，`ui.ts` 内联 SVG `#gFrame`） |
| 任务卡 | 皮质/毛边卡片 | 石质渐变卡片（`skin.css` 底部「sober stone」主题） |
| 伤害数字 | 大号金字 + WEAK POINT 标签 | 飘字系统（`ui.popup`），`WEAK` 后缀，字号随类型变化 |
| 怪物血条 | 顶部带角饰长条 | 顶部条 + 名牌（`bossbar`） |

结论：**以圆球 HUD + 石质面板为准**。概念稿 02 仅保留「挥砍光弧、命中火花、伤害数字」这三类反馈方向。
