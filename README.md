# 烬野：暗影回响

**烬野：暗影回响** 是一款单人第三人称狩猎与生存动作游戏。你将踏入永夜笼罩的火山荒岛，追踪并猎杀荒兽，采集素材、制作兵装、升级营地，最终重燃远古信标，直面岛上的远古霸主。

本作以《暗黑破坏神》的黑暗奇幻氛围作为美术方向参考，但为独立原创作品：使用冷月、火山余烬、荒原遗迹与石刻界面塑造压迫感，不包含其专有角色、标识、剧情或素材，也不代表官方关联。

## 可行性评估

**结论：本次风格重制可行性高。** 提供的《穴居人大战荒野》源码包已经包含可运行的 Three.js 游戏、完整的狩猎/探索/采集/制作流程，以及猎人、荒兽、首领、植被、环境和音频资源。项目不需要更换引擎或从零重写玩法，主要改造集中在夜景光照、地表色彩、雾与天空、营火/火山暖色焦点、战斗反馈和界面主题，现有资源也足以支撑本轮重制。

范围边界：成品是可玩的独立单机游戏原型，不以复刻 AAA 级内容量、任务线或专有美术资产为目标；未加入在线排行榜、账号、支付或后端服务。现有模型与动画优先复用，避免为风格调整重复制作同类资产。

## 本地运行与验证

项目基于 Three.js、TypeScript 与 Vite，需 Node.js 和 pnpm。首次运行先安装锁定依赖：

```bash
pnpm install --frozen-lockfile
```

启动本地预览：

```bash
pnpm dev -- --host 127.0.0.1 --port 3000 --strictPort
```

本地开发预览地址为 `http://127.0.0.1:3000/`。生产构建输出至 `dist/`：

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm smoke
```

`pnpm smoke` 在生产构建后运行浏览器冒烟测试并把截图保存到 `.work/previews/smoke/`。
